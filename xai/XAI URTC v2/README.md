explanation layer. The manuscript is `paper/main.pdf`. This v2 package
supersedes `xai/XAI UTRC` (v1, kept for history) and is the copy to submit.

## Contents

- `paper/main.tex`, `paper/main.pdf`: the manuscript (IEEEtran conference).
- `paper/main.docx`: a Word conversion of the compiled PDF (made with
  Microsoft Word's PDF import) for co-author review and commenting. It is
  a convenience copy: the LaTeX-built `main.pdf` is the submission
  document, and line-break hyphenation may be imperfect in the docx.
- `references.bib`: 16 entries, all cited in the manuscript; every field
  web-verified against publisher pages, Crossref, DBLP, or arXiv (see
  `citation_verification_notes.md`, including the 2026-08-09 full
  re-verification pass).
- `figures/`: all five paper figures as PDF (used by LaTeX) and PNG
  (preview), regenerated by `make_figures.py`.
- `make_figures.py`: builds every figure from primary artifacts (caches,
  CSVs, model bundle) at IEEE column sizes.
- `verify_numbers.py` / `verified_numbers.json`: recomputes every headline
  number in the paper from primary artifacts (metrics.json, SHAP caches,
  training frame, day explanations).
- `verify_numbers_extra.py` / `verified_numbers_extra.json`: tail
  statistics, the miss-case cap check, and the dedicated exact-SHAP run
  over all 431 heavy-smoke rows plus 2,500 medium-tier rows (bootstrap
  CIs backing the smoke non-monotonicity claim).
- `verify_numbers_v3.py` / `verified_numbers_v3.json`: written to resolve
  an adversarial audit of the draft; verifies the selection superlatives
  (worst miss, smoke/clean day), quantifies the failure class (46 rows
  with readings above 40 and all neighbor means below 5; regional group
  negative on all 46), recomputes the saturation plateau exhaustively
  (860 rows), measures the clip (never active on the sample), checks
  case-row reconstruction in float64 (5e-13), and fixes a sensor-id dtype
  bug that had silently emptied the earlier cap check (241 pre-cap rows
  above 75 exist among the 310 sensors; the miss row is genuinely 75.0).
- `verify_numbers_tiers_dayclustered.py` / `verified_numbers_tiers_dayclustered.json`:
  day-clustered bootstrap for the smoke-tier means and the medium-vs-heavy
  difference (heavy rows fall on only 31 days; the iid difference CI
  [0.008, 0.016] widens to [-0.004, 0.023] under day clustering, so the
  paper claims "no increase over medium" rather than a strict decrease).
- `DIRECTION.md`: the direction memo (thesis, outline, figure plan,
  verified-numbers policy) the paper was built from.
- `citation_verification_notes.md`: per-reference verification evidence.

## Rebuilding

From the repository root:

```
python "xai/XAI URTC v2/verify_numbers.py"
python "xai/XAI URTC v2/verify_numbers_extra.py"   # ~10 min (exact SHAP runs)
python "xai/XAI URTC v2/make_figures.py"
cd "xai/XAI URTC v2/paper"
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Requires the repo data files (p2_processed_v2.xls, pipeline parquets), the
model bundle `models/ensemble.joblib`, the xai caches in
`xai/outputs/cache/`, Python 3.14 with shap 0.50 / lightgbm / catboost /
matplotlib, and any LaTeX with IEEEtran.

## Provenance notes

- The paper reports the ensemble baseline 9.65 ug/m3 (the 30-feature
  model). During the earlier 38-feature study, a committed `shap_run.log`
  printed 6.682 with a constant 3.03 "additivity error" (a CatBoost
  expected_value read-order bug: the omitted term, 0.309422 x 9.808328 =
  3.0349, equaled the reported error exactly); upstream commit a57d415
  fixed the bug and regenerated all outputs, and later logs show zero
  additivity error.
- The SHAP interaction analysis was completed independently twice on
  2026-07-31 (this machine and upstream commit 0496598, same script,
  sample 300, seed 42); the two runs produced byte-identical
  `top_interactions.csv` tables (git resolved the add/add automatically),
  and all regenerated upstream CSVs match the paper's numbers to printed
  precision.
- The paper's robustness sentences (65.8% five-way ranking stability,
  rank correlation 1.0 with grouped permutation importance) and the
  sensor-clustered rho CIs cite upstream artifacts
  `xai/outputs/method_agreement.txt`, `group_importance_ci.csv`,
  `grouped_permutation.csv`, and `dependence_directions.csv`.
- The README claim of 774 heavy-tier rows was corrected to 431 after
  recounting from the training frame; the paper uses 431.
- `figures/fig1_system.*` (the pipeline schematic) was cut from the paper
  for the 5-page limit but is kept here for slides and the poster.
- Compiled figure numbers differ from artifact file names by one
  (fig2_global renders as Fig. 1, and so on) because of that cut.
- The draft passed a six-reviewer adversarial audit (AI-writing style,
  forensic number check, citation-claim alignment, scientific rigor,
  IEEE/URTC format, copy edit); all 70 findings were fixed or
  deliberately retained (the cut schematic; the v1 email placeholder is
  resolved in this version).
